# KST website visual direction

The website uses the existing KST SVG identity and code-native product-story illustrations in `src/components/landing/LandingStoryScene.vue`. It does not load a generated hero bitmap or copy a live application workspace.

- One light visual system: white surfaces, cool neutral text, restrained brand blue, consistent linework.
- Personal and team scenes explain input, tool use, and review. They are explicitly labelled as process illustrations, not live execution or customer results.
- Scenario buttons only switch local presentation content. No account data or business operations are requested.
- Finite entrance animation supports pause, resume, replay, and the operating-system reduced-motion preference.
- The rejected generated sculpture, its prompt, and previous landing source are preserved outside the repository in `D:/AmazonToolboxData/deliverables/kst-brand-redesign-20260920/before/`. The original PNG remains in the previous delivery's `source-art/` folder.
