# 自动化工具箱设计系统 v6 — 雾白矿蓝

> 明亮、精密、克制。通过清晰层级与可靠反馈建立高级感，不依赖深色背景、霓虹发光或装饰堆叠。

## 产品原则

- 产品是自动化效率工具，不是课程、训练进度或亚马逊真实业务后台。
- 用户选择业务、点击一次、等待自动完成；仅在脚本确实需要时请求用户完成一步。
- 用户端不展示成功率、预计时间、内部任务 ID、技术步骤或错误堆栈。
- 首页承诺可以保留，但不虚构进度、结果和后端没有的数据。
- 管理端允许运营指标与更高密度，用户端保持舒适密度。

## 颜色

| Token | 色值 | 用途 |
|---|---:|---|
| `--color-canvas` | `#F4F5F7` | 页面画布 |
| `--color-surface` | `#FCFCFD` | 卡片、侧栏、弹窗 |
| `--color-surface-premium` | `#F8F7F4` | 套餐与品牌价值区 |
| `--color-text` | `#182033` | 主文字 |
| `--color-text-secondary` | `#667085` | 辅助文字 |
| `--color-primary` | `#2D5FCA` | 主操作、选中、执行 |
| `--color-primary-soft` | `#EAF0FF` | 蓝色浅背景 |
| `--color-premium` | `#A98552` | 少量香槟铜价值点缀 |
| `--color-success` | `#168A63` | 完成、正常 |
| `--color-warning` | `#B7791F` | 等待用户、需关注 |
| `--color-danger` | `#C33D49` | 失败、危险操作 |
| `--color-border` | `#E1E5EB` | 边界与分隔 |

蓝色负责信任与执行，香槟铜只负责价值层级。红色不得用于一般提醒。旧 `--studio-*` 变量仅作为迁移别名，新代码使用语义 Token。

## 排版、间距和表面

- 字体：Inter、苹方、微软雅黑、系统字体。
- 页面标题：28px；区块标题：18px；正文：14px；辅助信息：12–13px。
- 间距只使用 4/8/12/16/20/24/32/40/48px。
- 卡片圆角 14px，输入和按钮圆角 10px，弹窗圆角 18px。
- 阴影仅使用 `--shadow-low`、`--shadow-medium`、`--shadow-overlay`。
- 卡片必须保留细边界；不得仅靠夸张阴影区分层级。

## 动效

| 类型 | 时长 |
|---|---:|
| 按压反馈 | 100ms |
| hover/颜色 | 160ms |
| 内容与弹窗 | 230ms |
| 页面和抽屉 | 320ms |
| 启动光轨 | 420ms |
| 运行呼吸 | 2100ms |

- 动画只使用 `transform` 和 `opacity` 等低成本属性。
- 启动光轨不阻塞请求，也不代表请求成功。
- 等待用户提示只脉冲三次；完成只确认一次；失败不抖动屏幕。
- `prefers-reduced-motion` 下取消非必要位移、光轨和循环动效。

## 核心状态

| 状态 | 用户文案 | 颜色 |
|---|---|---|
| `idle` / `preparing` | 正在准备 | 矿物蓝 |
| `running` | 正在自动处理 | 矿物蓝 |
| `waiting_user` | 需要你的操作 | 琥珀 |
| `paused` | 已暂停 | 中性灰 |
| `completed` | 处理完成 | 成功绿 |
| `failed` | 本次未完成 | 失败红 |
| `cancelled` | 已停止 | 中性灰 |

工作区只呈现“准备、执行、核验、完成”四段业务阶段。底层脚本步骤、重试与计时只进入日志或管理诊断。

## 组件与布局

- `PageHeader`：标题、说明和操作区。
- `AppSurface`：default/soft/premium 表面与两级高度。
- `StatusBadge`：由业务状态映射颜色。
- `EmptyState`：统一空、错误和无权限状态。
- `DataToolbar`：后台筛选与操作。
- `AppTransition`：统一进入离开并支持 reduced motion。

用户端侧栏 224px、顶部栏 60px，均采用明亮表面。后台共享 Token，但采用紧凑表格密度。1024px 以下侧栏变为抽屉，页面不得产生横向滚动。
