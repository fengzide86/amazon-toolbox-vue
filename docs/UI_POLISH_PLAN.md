# 自动化工具箱明亮高级感实施基线

> 状态：v6 已落地。本文档用于后续迭代防止产品定位和视觉方向偏移。

## 产品路径

```text
授权码登录 → 选择工具 → 一键启动 → 系统自动处理
                                  ↓
                         必要时完成一个步骤
                                  ↓
                    完成 / 重新执行 / 工具帮助
```

用户不需要理解脚本、成功率、预计时间和内部步骤。界面只回答：当前能做什么、系统是否正在处理、是否需要用户操作、结果与下一步是什么。

## 信息架构

1. 工具箱：核心入口，展示真实工具状态和唯一启动操作。
2. 执行记录：展示工具、时间、结果、再次使用或帮助入口。
3. 套餐与授权：先展示当前套餐，再比较真实权益。
4. 设备授权：首先说明当前电脑是否已授权，席位数量为次要信息。
5. 工具帮助：承接授权、设备、执行失败上下文和人工工单。

旧 Dashboard 继续兼容跳转到工具箱。管理端保留现有十个业务路由和运营指标。

## 核心体验基线

- 工具页保持双列紧凑卡片；小屏单列。
- 可用、套餐未包含、维护中必须有不同的文案和操作行为。
- 启动期间所有工具卡禁用，防止重复请求；光轨仅做即时反馈。
- 工作区以目标页面为主体，辅助栏固定呈现四段业务阶段。
- 运行时防止误操作；等待用户时解除遮挡并只给一个继续按钮。
- 失败说明停止位置和下一步，技术详情不直接暴露给用户。
- 同一电脑退出再登录必须保留设备身份，不重复占用席位。
- 授权码与管理员密码输入框反复聚焦均需显示光标。

## 视觉基线

- 主题为“雾白矿蓝 / 明亮精密”。
- 画布 `#F4F5F7`，表面 `#FCFCFD`，主色 `#2D5FCA`，价值点缀 `#A98552`。
- 禁止大面积黑色、廉价渐变、发光边框和玻璃拟态堆叠。
- 高级感来自留白、细边界、字体层级、交互节奏和一致状态。
- 用户端舒适密度；管理端紧凑密度。

## 技术边界

- `taskRun` 与真实自动化事件是执行状态唯一来源。
- 不建立模拟进度、第二套计时器或由动画驱动的业务状态。
- 不改变既有 API、数据库、IPC 和权限含义来适配视觉。
- 缺少可靠数据时省略模块，不临时虚构接口。
- 新样式使用语义 Token 和公共组件；旧 `--studio-*` 仅用于兼容迁移。

## 发布前验证

- 前端完整单元测试与生产构建通过。
- 登录、同机退出重登、设备迁移、解绑释放席位回归通过。
- 自动化准备、运行、等待用户、暂停、完成、失败、取消全部可用。
- 1365×768、1920×1080、1024 和窄窗口无溢出。
- reduced-motion、键盘操作和焦点状态可用。
